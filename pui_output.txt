   INPUT DATA PEMAIN 
       Tujuan 
Menyimpan profil lengkap pemain sebagai basis analisis. 
🖥 Halaman: "Data Pemain" 
  A. Form Tambah Pemain 
Field yang perlu ada: 
• Foto pemain 
• Nama lengkap 
• Nomor punggung 
• Posisi utama (GK, DF, MF, FW) 
• Posisi alternatif 
• Tanggal lahir 
• Tinggi badan 
• Berat badan 
• Status (aktif / cedera / suspend) 
• Tipe pemain (Attacking / Defensive / Balanced) 
  B. Atribut Performa Dasar (Rating 1–100) 
• Speed 
• Stamina 
• Passing 
• Shooting 
• Dribbling 
• Defensive skill 
• Vision 
  C. Tabel Data Pemain 
Kolom: 
• Foto 
• Nama 
• Posisi 
• Stamina 
• Status 
• Action (Edit / Delete / Detail) 
   STATISTIK PERFORMA 
       Tujuan 
Menampilkan performa pemain per pertandingan. 
🖥 Halaman: "Statistik Performa" 
  A. Input Statistik per Match 
Field: 
• Pilih match 
• Pilih pemain 
• Menit bermain 
• Rating (1–10) 
• Jumlah sprint 
• Jumlah tembakan 
• Jumlah assist 
• Jumlah kesalahan 
• Pelanggaran 
• Kartu 
  B. Visualisasi Statistik 
• Grafik performa per pemain 
• Grafik rata-rata rating 
• Perbandingan pemain 
Gunakan: 
• Line chart 
• Bar chart 
• Radar chart 
   MONITORING STAMINA 
       Tujuan 
Mengetahui kelelahan pemain untuk dasar rule. 
🖥 Halaman: "Monitoring Stamina" 
  A. Input Data Fisik 
• Stamina awal (%) 
• Stamina akhir (%) 
• Total jarak lari (km) 
• Intensitas latihan (Low / Medium / High) 
  B. Indikator Warna 
• Hijau (≥ 70%) 
• Kuning (40–69%) 
• Merah (< 40%) 
  C. Grafik Tren Stamina 
Per pemain per minggu. 
   DASHBOARD PERTANDINGAN 
       Halaman Utama (Home) 
Berisi ringkasan: 
  A. Ringkasan Tim 
• Jumlah pemain aktif 
• Jumlah pemain cedera 
• Rata-rata stamina tim 
• Rata-rata rating tim 
  B. Live Match Panel (Simulasi) 
• Skor saat ini 
• Menit pertandingan 
• Status (Menang / Seri / Kalah) 
• Pemain stamina kritis (alert) 
  C. Rekomendasi (Dari Rule Engine Basic) 
   PERTANDINGAN (MATCH MANAGEMENT) 
🖥 Halaman: "Match" 
  A. Tambah Match 
• Nama pertandingan 
• Lawan 
• Tanggal 
• Kompetisi 
• Formasi awal 
  B. Starting XI 
Checklist 11 pemain 
  C. Catatan Pertandingan 
• Skor akhir 
• Hasil (W/D/L) 
• Catatan pelatih 
   RIWAYAT MATCH 
🖥 Halaman: "Riwayat" 
Tabel: 
• Tanggal 
• Lawan 
• Skor 
• Hasil 
• Total substitusi 
• Detail 
Klik detail → lihat: 
• Statistik tim 
• Rekomendasi yang pernah muncul 
• Performa pemain 
   RULE ENGINE (BASIC VERSION) 
       Inti sistem kamu. 
🖥 Halaman: "Manajemen Rule" 
  A. Tambah Rule 
Contoh form: 
IF: 
• Stamina < 40 
• Menit > 60 
• Status pertandingan = Kalah 
THEN: 
• Rekomendasi substitusi 
  B. Tipe Rule 
• Fatigue Rule 
• Performance Rule 
• Tactical Rule 
  C. Status Rule 
• Aktif / Nonaktif 
  D. Simulasi Rule 
Test dengan data dummy.

• Evaluasi efektivitas rule 
Export: 
• PDF
